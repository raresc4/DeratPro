4. How it works: 3 numbered steps in a horizontal timeline (Ne suni → Evaluare →

- Typography: one modern sans-serif (e.g. Inter or Manrope), clear hierarchy.
- Rounded cards, generous whitespace, subtle shadows, consistent 8px spacing.
- Line icons, consistent stroke weight.
- All copy in Romanian.

Provide desktop and mobile frames. Show the form validation error state and
the success state.
